ETB2B Awards V19.18 — Responsive Device QA

What changed
- Public website now uses container-responsive rules, so the Website Studio Tablet/Mobile preview behaves like the real device instead of merely shrinking a desktop layout.
- Tablet and mobile navigation remain usable with horizontal menu scrolling and compact branding.
- Hero, branding artwork, registration forms, popup registration, metadata, CTAs and all five hero layouts adapt to narrower screens.
- Homepage sections, speakers, sponsors, agenda, resources, contacts, FAQs, About Vertical and Glimpse layouts are responsive.
- Agenda session content stays left aligned and stacks cleanly on phones while the Agenda title still follows global alignment.
- Glimpse carousel / reel / coverflow / depth stack layouts resize for touch screens.
- Footer and Scroll-to-top are mobile safe.
- Standalone award pages (Categories, Jury, Entry Guidelines, Judging Criteria, FAQ, Contact, Previous Edition and Rewards) are responsive.
- Website Studio itself has responsive controls, tabs, asset cards, drawers, layout galleries, registration fields and device preview toolbar.

Recommended QA widths
- Desktop: 1440 x 900
- Tablet landscape: 1024 x 768
- Tablet portrait: 820 x 1180
- Mobile: 390 x 844
- Small mobile: 360 x 800
