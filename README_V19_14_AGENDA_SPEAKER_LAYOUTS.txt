ETB2B Awards V19.14 - Agenda & Speaker Layout Expansion

What changed
- Added new agenda layouts at the TOP of Agenda > Layout Design:
  1. Executive Session Rows
  2. Accent Rail
  3. Speaker Session Board
  4. Clean Schedule Table
- Agenda now shows linked speaker portraits/details where available.
- Added new speaker layouts at the TOP of Speakers > Layout Design:
  1. Professional Grid
  2. Compact Cards
  3. Featured Spotlight
  4. Enhanced List
  5. Gallery Showcase
  6. Split Screen
- Every homepage section now has two visibility controls in Customize > Content & data:
  - Section title: ON by default; turn OFF to hide the section heading on the public site.
  - Navigation label: ON by default; turn OFF to remove that section from the public nav.
- Navigation-label visibility stays synchronized with the section's Nav toggle.

Suggested test
Website Studio > Sections > Agenda > Customize > Layout Design
Try Executive Session Rows and Accent Rail.
Then Speakers > Customize > Layout Design and try Professional Grid / Featured Spotlight.
In any section, turn Section title OFF and confirm the public heading disappears.
Turn Navigation label OFF and confirm the item disappears from Website Studio > Navigation and the public navigation.
