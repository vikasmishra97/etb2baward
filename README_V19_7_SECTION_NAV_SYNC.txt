ETB2B Awards V19.7 — Section-managed navigation & editable award pages

What changed
- Homepage sections and dedicated award pages now live together under Website Studio > Sections.
- Dedicated pages: Categories, Jury, Entry Guidelines, Judging Criteria, T&C, FAQs, Contact Us, Previous Edition, Rewards.
- Every dedicated page has a Customize action for page heading, intro, nav label and page-specific content.
- Homepage sections have a Navigation label field plus a Nav visibility control.
- Award pages have On/Off and Nav controls in Sections.
- Website Studio > Navigation is now an ordering workspace: visibility is synced from Sections and menu items can be dragged to reorder.
- Navigation order is saved per award.
- Public navigation automatically puts overflow links into More.
- Smart scroll behavior: at the top the full header is visible; scrolling down hides navigation; scrolling up shows only the compact menu row.
- The Express Interest / Nominate CTA is hidden from the compact scrolled navigation.
- Existing V19.6 section/page visibility is migrated where possible.

Suggested test
1. Website Studio > Sections.
2. Turn Entry Guidelines OFF and confirm it disappears from Navigation.
3. Turn it back ON, then turn its Nav switch ON.
4. Click Customize and change the page title / intro / guideline steps.
5. Website Studio > Navigation: drag Entry Guidelines above Jury.
6. Save draft, open public preview, and check the new order.
7. Scroll down: nav hides. Scroll upward: only the compact nav row returns, without Express Interest.
