ETB2B Awards V19.10

Updates
1. Header Studio sub-navigation (Basics / Hero Media / Brand & SEO / Style) no longer floats over editor content.
2. Preview status/device toolbar no longer floats over the live preview. It stays as a normal toolbar above the canvas.
3. Public registration submissions now save a registration ID, award slug, source, timestamp and all configured form fields.
4. Reports > Acquisition now includes live Website Registrations KPIs and a recent registrations table.
5. Registration CSV export is available from Reports > Acquisition.
6. Reports refresh registrations when the page regains focus or another browser tab submits a registration.

Prototype note
Registration data is stored in browser localStorage, so the public site and Reports must be opened on the same Vercel domain/browser profile for the demo. A production backend will make this cross-device and multi-user.
